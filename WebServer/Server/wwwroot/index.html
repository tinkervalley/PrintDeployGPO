ONE SYSTEM TASK
Deploy with Group Policy
  1. Set the server URL in Settings and make sure clients can reach it.
  2. Download the generated startup script. It includes the server’s pinned public key.
  3. Add it to Computer Configuration → Policies → Windows Settings → Scripts → Startup → PowerShell Scripts, with parameters blank.
  4. The bootstrap retrieves the signed task definition and client bundle, then registers one SYSTEM task. It runs after startup and polls for assignments on the configured schedule.
